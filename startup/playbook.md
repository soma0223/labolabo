# 起業と経営の操作的定義（Claudeが従う基準）

最終更新：2026年11月12日。ユーザーの指摘（「起業と経営という概念を操作化して詳しくなって」）を受けて作成。
以後、すべての提案はこの基準にかけてから出す。

## 1. 起業とは何か

### 1.1 理論上の定義（5つの見方）

| 見方 | 起業とは | 出どころ | この企画への意味 |
|---|---|---|---|
| 機会 | 機会を見つけ、見きわめ、形にすること | シェーンとヴェンカタラマン（2000） | 見つける・見きわめる・形にする、は別の工程 |
| 不確実性 | 確率が分からない状況で判断を引き受けること | ナイト（1921） | 計算できる危険ではなく、分からなさを減らすのが仕事 |
| 新結合 | 既存のものの新しい組み合わせ | シュンペーター | 新しい機能でなくてよい。相手・経路・組み合わせの新しさでよい |
| 気づき | 他人が見落としている価格や需要のずれに気づくこと | カーズナー | 転売（安く仕入れて高く売る）はこの型。ユーザーの「既存のものをリセール」はここ |
| 探索 | 繰り返せて広げられる事業の形を探す、一時的な活動 | ブランク | 既知の形をなぞる商売（物販など）と、未知の形を探す起業は別物 |

### 1.2 操作的定義

**起業＝分からないことだらけの中で、「特定の人が対価（お金・時間・注意）を払い続ける交換の仕組み」を、限られた資源のうちに見つけて成り立たせること。**

成り立っているかどうかは、次の6つの要素が観察できるかで判定する。

| 要素 | 問い | 観察できる証拠 | よく使う目安（実務の経験則。厳密な検証は限られる） |
|---|---|---|---|
| E1 顧客 | 誰の、どんな用事か | 名前を挙げられる人がいる。その人が今、別の手段に時間かお金を使っている | 代わりの手段が何もないなら、用事が弱い疑い |
| E2 価値 | 代わりの手段よりこちらを選ぶか | 頼まれなくても繰り返し使う。なくなると困ると言う | 「使えなくなったら非常に残念」が4割（エリス。数値はClaudeの記憶） |
| E3 経路 | 知らない人にどう届くか | 同じやり方を繰り返すと、同じくらいの費用で人が来る | 1人獲得する費用が測れている |
| E4 収益 | 誰かが、かかる費用より多く払うか | 1人あたりの儲けが正 | 1人から得る総額が、獲得の費用の3倍（記憶） |
| E5 守り | なぜ真似されて終わらないか | 切り替えの手間、蓄積したデータ、界隈での定着など | 5つの競争要因（ポーター） |
| E6 持続 | 作り手が続けられるか | お金・時間・やる気が尽きる前に次の証拠が出る | 許容できる損失（サラスバシー） |

### 1.3 段階（どの順で証拠を積むか）

ブランクの顧客開発をもとにした段階。各段階に、次へ進む条件を置く。

| 段階 | 目的 | 進む条件（証拠） | やってはいけないこと |
|---|---|---|---|
| S0 仮説 | 6要素を仮説として書き出す | 6要素すべてに仮の答えがあり、一番危ういものが分かっている | 案を並べて選ぶだけ |
| S1 課題の確認 | E1が本当か | 複数の人が、その用事に今も時間かお金を使っている | 感想を聞いて満足する |
| S2 解決の確認 | E2が本当か | 最小限のものを、頼まれなくても繰り返し使う人がいる | 機能を足して解決しようとする |
| S3 経路と収益の確認 | E3・E4が本当か | 知らない人が繰り返せる形で来て、1人あたりの儲けが正 | 経路が見つかる前に広告や機能にお金と時間を使う |
| S4 拡大 | 広げる | 上が成り立っている | S3の前に広げる（早すぎる拡大） |

原則：**一番危うい仮説から、一番安い方法で確かめる。** 確かめる順は、作りやすさではなく「外れたら全部が崩れる度合い」で決める。

## 2. 経営とは何か

### 2.1 理論上の定義

| 見方 | 経営とは | 出どころ |
|---|---|---|
| 目的 | 顧客を創り出すこと。基本の働きは2つ（売れる仕組みと新しい価値） | ドラッカー |
| 戦略 | 何をやらないかを選ぶこと | ポーター |
| 戦略の中身 | 診断・基本方針・一貫した行動、の3つがそろったもの | ルメルト |
| 制約 | 全体の成果は一番細い所で決まる。そこに集中する | ゴールドラット（制約理論） |
| 循環 | 計画し、実行し、確かめ、直す | デミング |

### 2.2 操作的定義

**経営＝目的に向けて、限られた資源（時間・お金・注意）の配り方を決め、結果を測り、直し続けること。**

一流かどうかは、次の行動が観察できるかで判定する。

| 行動 | 一流 | 素人 |
|---|---|---|
| M1 目的から始める | 先に目的と制約を確かめ、そこから手段を導く | 手段（案）から始め、後で目的に合わないと分かる |
| M2 診断する | 「今の一番の難所はどこか」を特定してから動く | 思いついた順に動く |
| M3 捨てる | やらないことを理由つきで決める | 選択肢を並べ、決めない |
| M4 仮説を明示する | 判断の前提を書き出し、どれが未確認かを分ける | 前提を確かめずに進める |
| M5 数字で考える | 1人あたりの儲け、費用、時間を概算で持つ | 「需要がありそう」で止まる |
| M6 先に基準を決める | 確かめる前に「どうなったら続け、どうなったらやめるか」を決める | 結果を見てから都合よく解釈する |
| M7 取り返しで分ける | 取り返しのつく判断は速く、つかない判断は慎重に（ベゾス） | 全部を同じ重さで扱う |
| M8 証拠で直す | 反する証拠が出たら見立てを変え、変えた理由を残す | 最初の案に固執する、または理由なく変える |

## 3. この会話でのClaudeの失敗（基準に照らした診断）

| 失敗 | 当たる基準 | 何が起きたか |
|---|---|---|
| 目的を聞く前に案を掘った | M1 | 英語アプリを事業候補として掘り、3往復してから「起業で何がほしいか」を聞いた |
| 制約を確かめなかった | M1・M4 | 「人に会える」を前提に3案（インターン先、サークル、塾）を出し、3回却下された |
| 並べて決めなかった | M3 | 5案の表を出して選ばせた。「的外れ」と言われた |
| 理論を飾りに使った | M2 | 案を出した後に理論を添えた。理論から案を導いていなかった |
| 経路と収益を後回しにした | S0・E3・E4 | どの案でも「どう届くか」「誰が払うか」を弱点の欄に書くだけで、案を選ぶ基準にしなかった |
| 反射で差別化を機能に求めた | M4 | 根拠なく「競合がいる → 機能で差」と置いた |
| 作りやすさで順番を決めた | 1.3の原則 | 「既存アプリを出せば早い」と、確かめるべき仮説ではなく手間で決めた |

## 4. 以後、提案の前に必ず通す点検

1. 目的と制約に合っているか（M1）
2. 6要素（E1〜E6）のうち、どれについての提案か
3. 今の段階（S0〜S4）に合っているか。先の段階の作業をしていないか
4. 前提は何か。確認済みと未確認を分けたか（M4）
5. 一番危うい仮説を、一番安く確かめる手になっているか
6. 概算の数字があるか（M5）
7. 続ける条件とやめる条件を先に書いたか（M6）
8. 1つに絞って勧めているか。捨てた理由を書いたか（M3）
