**読み取り**
- 一番多い失敗は「誰も欲しがらないものを作る」こと。この企画で関門1（困りごとがあるか）を最初に置いた判断は、この割合と合っている。
- 「やめること」は失敗ではなく、科学的な進め方の成果として研究で測られている。関門で戻ることを成果と扱う方針（flow.md）を裏づける。

## 2. 競合（会社と規模）

### 2.1 大手の推し活アプリの撤退

- **Oshibana（株式会社ブックリスタ）は、2026年8月20日に機能開発を終了し、「見る専用モード」に移った。** 2021年公開、累計110万〜120万ダウンロード、Z世代中心。ウィジェット、動く壁紙、キーボード、記念日、予定、推し活メモ。
- 終了の理由は発表に書かれていない（推測で埋めない）。
- 同時に「推しデータの書き出し」を公開し、「一部の他社製のアプリでもご利用いただけます」と案内している。

**読み取り（Claudeの推論）**
- 100万を超えるダウンロードがあっても、会社として続ける判断にならなかった。U6（ホーム画面に置く）の系統でお金を回す難しさを示す1例。
- 一方で、移り先を探している利用者がいる。書き出したデータを読み込めるアプリは、その人たちの移り先になりうる（E3の候補）。ただし、見る専用モードでも作成済みのウィジェットは使えるので、急いで移る人がどれだけいるかは分からない。

### 2.2 交換・譲渡（U4）はすでに混んでいる

| サービス | 中身 |
|---|---|
| Yahoo!フリマ グッズ交換 | 推し登録、匿名配送、配送状況の確認、募集の専用フォーム |
| トレポータル | グッズ単位の検索、取引の評価、交換スケジュール管理 |
| 推しトレ | 「譲」「求」の管理、条件の合う相手探し、Xでの募集画像の作成 |
| グッチェン、SwapPark（匿名対応）、交換堂 | 交換の専門サイト・アプリ |
| 推しグッズ交換メーカー、おとりひき | Xでの募集文の作成、取引の管理 |

- メルカリは交換・半交換を禁止している。
- Xでの交換は、住所の交換と発送の管理を自分でする必要がある。新しいアカウントは詐欺を警戒されて避けられやすい。

**訂正**：作戦メモ11.3で「交換・譲渡の約束は、どのアプリも扱っていない」と書いたのは誤り。レビューを集めた36本の外に、専門のサービスが少なくとも7つあった。

## 3. 障壁

### 3.1 ストアに出すとき

| 障壁 | 中身 | 強さ |
|---|---|---|
| **本名が「販売元」として表示される** | Appleの開発者登録を個人で行うと、App Storeに本名が出る。屋号にするには組織として登録し直す必要がある（法人など） | △（複数の個人開発者の記事で一致） |
| 年会費 | Apple Developer アプリ経由で年12,800円（Web経由より安い） | △ |
| 手数料 | 小規模事業者向けの制度で、売上の15% | ○（Apple公式のページが存在。率はClaudeの記憶） |
| 有料にする場合の表示義務 | 特定商取引法の表示（氏名・住所・電話番号など）が必要とする解説がある。ストア経由の販売で個人がどこまで負うかは要確認 | ？ |

### 3.2 お金と税金（学生の場合）

| 障壁 | 中身 | 強さ |
|---|---|---|
| 確定申告 | アプリの収入が雑所得で年20万円を超えると必要。20万円以下でも住民税の申告は必要 | ○（会計ソフト会社の解説で一致） |
| 親の扶養 | 学生の収入が一定額を超えると、親の扶養控除から外れる。2026年分の上限は「123万円」と「136万円」の記述があり食い違う | ？（要確認。収入が大きくなった時点で確かめる） |

| 分かったこと | 出どころ | 強さ |

**読み取り**：広告で100人を集めると約36万円。この企画の予算では、広告は選択肢にならない。届け方は、ストアの検索、X、移り先を探している人、の無料の経路に限られる。

## 4. この企画への影響

| 項目 | 変わること |
|---|---|
| 進め方 | 変えない。関門1（困りごと）を先に確かめる方針は、失敗の理由の一番（需要がない）と研究の両方に合う |
| U6（ホーム画面） | 大手が100万ダウンロード超で撤退した。お金を回す難しさの証拠（1例）。同時に、移り先を探す人という届け方の候補が生まれた |
| U4（交換・譲渡） | 専門サービスが7つ以上あり、空いている場所ではなかった。お姉さんへの追加の聞き取りでは「どのサービスを知っていて、なぜXでやっているのか」を足す |
| 公開するとき | 本名が出ることを、出す前にユーザー本人が判断する必要がある（取り返しがつきにくい判断。playbook M7） |
| 集客 | 広告は使えない前提で、無料の経路を工程5で設計する |
